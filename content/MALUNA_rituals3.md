# Логика подбора ритуала для бота

**Сколько ритуалов** — 176. Из них 144 — по одному на каждую комбинацию первых четырёх вопросов (время суток 3 × время 3 × настроение 4 × что хочется 4). Ещё 32 — по одному ритуалу на каждый предмет в каждой теме (8 предметов × 4 темы «что хочется»), на случай когда дома есть только одна вещь. Все 176 текстов разные, повторов нет.

**Шаг 1. Отбор по четырём ответам** — Бот берёт ответы на первые четыре вопроса и отбирает строки, где совпадают все четыре столбца: «Время суток», «Время (мин)», «Настроение», «Что хочется». Подходящих строк будет одна или несколько.

**Шаг 2. Выбор по вопросу «Что есть дома»** — Если строка одна — это и есть ответ. Если строк несколько, бот выбирает ту, все продукты которой пользователь отметил в последнем вопросе. Если таких несколько — берём ту, где продуктов больше (ритуал полнее). Если пользователь отметил только один предмет — подойдёт строка из блока одиночных ритуалов именно с этим предметом.

**Шаг 3. Запасной вариант** — Если ни у одной отобранной строки продукты не совпали с тем, что есть у пользователя, бот берёт строку с наименьшим количеством продуктов и добавляет в конец фразу вроде «Если чего-то из этого нет под рукой — просто пропусти этот шаг». Эту фразу удобно один раз прописать в самом боте, не трогая таблицу. Так пользователь никогда не остаётся без ответа.

**Что показывать пользователю** — Столбец «Название ритуала» — как заголовок сообщения, столбец «Текст ритуала» — как само сообщение. Столбец «Нужные продукты» можно вывести отдельной строкой в духе «Понадобится: …» или не показывать вовсе: продукты уже названы внутри текста.

**Продукты и длительность** — В основном блоке количество продуктов зависит от выбранного времени: 5 минут — 1 продукт, 15 минут — 2, 30 минут — 3. В блоке одиночных ритуалов всегда ровно один продукт, а длительность подобрана под сам предмет (например, ванна не может занимать 5 минут).


## Формат столбцов

**Время суток** — Ровно одно значение: утро / день / вечер.

**Время (мин)** — Ровно одно число: 5 / 15 / 30.

**Настроение** — Ровно одно значение: устала / тревожно / хочется вдохновения / радостно.

**Что хочется** — Ровно одно значение: отдохнуть / взбодриться / позаботиться о коже / создать уют.

**Нужные продукты / предметы** — От 1 до 3 значений через запятую, строго из списка последнего вопроса: свечи MALUNA, гидрофильное масло MALUNA, очищающий гель MALUNA, увлажняющий крем MALUNA, душ, ванна, кофе, чай.
